## 3. Newman-ы үр дүн

| Ажиллуулалт | Файл | requests | assertions executed | assertions failed | exit code |
|---|---|---|---|---|---|
| PASS | `results/newman-pass.txt` | 25 | **53** | 0 | **0** |
| FAIL | `results/newman-fail.txt` | 25 | 53 | 1 | **1** |
| DOWN | `results/newman-down.txt` | 25 (бүгд ECONNREFUSED) | 53 (бүгд fail) | 53 | **1** |

**Тестийн тоо:** 11 тестийн бүлэг, 25 хүсэлт, **53 assertions** (`results/newman-pass.txt`-тэй таарна).

**FAIL:** `lab05-collection-fail.json`-д T1-ийн хүлээгдэх статусыг 201-ийн оронд зориуд 200 болгосон тул 1 assertion унаж, exit code 1 гарсан. Үндсэн `lab05-collection.json` зөв хэвээр.

**DOWN:** Сервер унтарсан үед хүсэлт серверт хүрэхгүй `ECONNREFUSED` гарна. Энэ нь интерфейсийн (холболтын) алдаа бөгөөд oracle-ийн алдаа биш: oracle нь хариуг хүлээн авсны дараа утгыг шалгадаг, харин энд хариу ирээгүй тул шалгах зүйл байхгүй.

## 4. Дүгнэлт

Дизайны 5 алхмаас хамгийн их бодол шаардсан нь сонголтуудыг тодорхойлох, төлөөлөх утгыг сонгох алхам байлаа, учир нь оюутан, хичээл, урьдач нөхцөл гэсэн хамааралтай шинж чанаруудыг бие даасан сонголт болгож салгах хэрэгтэй болсон. Боломжгүй хослол тааралдсан: оюутан байхгүй үед "үзсэн хичээл урьдачийг хангана/хангахгүй" гэдэг сонголт утгагүй, учир нь үзсэн хичээлийн жагсаалт оюутан байж л оршино. Үүнтэй адил хичээл байхгүй үед урьдач нөхцөл тодорхойгүй тул эдгээр хослолыг тусад нь тест болгоогүй. Давхар алдааны хослолоор сервер алдааг аль дарааллаар шалгадгийг тогтоосон: T7 дээр оюутан ба хичээл хоёулаа байхгүй үед ERROR_NO_STUDENT, T8 дээр идэвхгүй оюутан ба урьдач дутуу үед ERROR_INACTIVE_STUDENT буцсан. Иймээс сервер эхлээд оюутны байхгүй байдал, дараа нь идэвхгүй байдал, дараа нь хичээл, хамгийн сүүлд урьдач нөхцөлийг шалгадаг. Тестүүд энэ серверт согог олоогүй бөгөөд 53 assertion бүгд spec-ийн дагуу давсан. Харин спецификацид тодорхойгүй байсан давхар алдааны дарааллыг тестээр тогтоож чадсан нь гол ашиг байлаа. FAIL ажиллуулалтад нэг oracle-ийг зориуд буруу болгосон (201-ийн оронд 200) тул 1 assertion унаж, сервер ажиллаж байхад ч exit code 1 гарсан. DOWN ажиллуулалтад сервер унтарсан тул хүсэлт хариу авалгүй ECONNREFUSED гарсан бөгөөд энэ нь oracle-ийн биш, холболтын (интерфейсийн) алдаа юм. Хоёр тохиолдолд exit code 1 ч гэсэн шалтгаан нь өөр тул CI дээр гаралтын текстээр нь ялгана.
