| Сонголт | Эквивалент анги | Төлөөлөх утга |

| studentID-гийн байдал | идэвхтэй | `B_T1`, status=`active` |
| | идэвхгүй | `B_T3`, status=`inactive` |
| | байхгүй | `NOSUCH_T2` |
| | дутуу (талбаргүй) | studentID-гүй хүсэлт |
| Оюутны үзсэн хичээл | урьдач хангана | `["CS201"]` |

## 2. Спецификацийн хүснэгт

| # | Тест | Setup | Хүлээгдэх статус | Хүлээгдэх result |
|---|---|---|---|---|
| T1 | Happy path | идэвхтэй оюутан (CS201 үзсэн), CS313 урьдач CS201 | 201 | `OK`, registrationID тоо |
| T2 | Оюутан байхгүй | зөвхөн хичээл | 200 | `ERROR_NO_STUDENT` |
| T3 | Оюутан идэвхгүй | inactive оюутан, хичээл | 200 | `ERROR_INACTIVE_STUDENT` |
| T4 | Хичээл байхгүй | идэвхтэй оюутан | 200 | `ERROR_NO_COURSE` |
| T5 | Урьдач огт хангаагүй | оюутан `[]`, урьдач CS201 | 200 | `ERROR_PREREQUISITES`, missing=`["CS201"]` |
| T6 | Урьдач зарим нь дутуу | оюутан CS201, урьдач CS201+CS202 | 200 | `ERROR_PREREQUISITES`, missing=`["CS202"]` |
| T7 | Давхар алдаа: оюутан ба хичээл хоёул байхгүй | — | 200 | `ERROR_NO_STUDENT` (оюутны шалгалт түрүүлнэ) |
| T8 | Давхар алдаа: идэвхгүй + урьдач дутуу | inactive оюутан `[]`, урьдач CS201 | 200 | `ERROR_INACTIVE_STUDENT` (идэвхгүй нь урьдачаас түрүүлнэ) |
| T9 | Хязгаар: урьдачгүй хичээл, хоосон coursesTaken | оюутан `[]`, урьдач `[]` | 201 | `OK` |
| T10 | Хязгаар: courseID дутуу | — | 400 | `ERROR_BAD_REQUEST` |
| T11 | Хязгаар: буруу JSON | — | 400 | `ERROR_BAD_JSON` |

Тест бүр өөрийн өвөрмөц ID-тай (`B_T1`, `CS313_T1` ...) setup-ээ өөрөө хийдэг тул бие даасан, давтан ажиллуулахад аюулгүй. registrationID-ийн яг утгыг шалгаагүй, зөвхөн тоо мөн эсэхийг шалгасан.

## 3. Newman-ы үр дүн

| Ажиллуулалт | Файл | requests | assertions executed | assertions failed | exit code |
|---|---|---|---|---|---|
| PASS | `results/newman-pass.txt` | 25 | **53** | 0 | **0** |
| FAIL | `results/newman-fail.txt` | 25 | 53 | 1 | **1** |
| DOWN | `results/newman-down.txt` | 25 (бүгд ECONNREFUSED) | 53 (бүгд fail) | 53 | **1** |

**Тестийн тоо:** 11 тестийн бүлэг, 25 хүсэлт, **53 assertions** (`results/newman-pass.txt`-тэй таарна).

**FAIL:** `lab05-collection-fail.json`-д T1-ийн хүлээгдэх статусыг 201-ийн оронд зориуд 200 болгосон тул 1 assertion унаж, exit code 1 гарсан. Үндсэн `lab05-collection.json` зөв хэвээр.

**DOWN:** Сервер унтарсан үед хүсэлт серверт хүрэхгүй `ECONNREFUSED` гарна. Энэ нь интерфейсийн (холболтын) алдаа бөгөөд oracle-ийн алдаа биш: oracle нь хариуг хүлээн авсны дараа утгыг шалгадаг, харин энд хариу ирээгүй тул шалгах зүйл байхгүй.
